# nl2sh · 说人话，出命令

> **GDUST Linux 协会 AI 网页设计大赛 · 赛道三「智能交互与应用」参赛作品**
>
> 中文说需求 → 真实大模型生成 Shell 命令 → **浏览器内的 Linux 沙箱真的跑一遍** →
> 跑不通就把沙箱的真实报错喂回模型自动修正 → 跑通了才允许复制。

🔗 **在线体验：<https://muxinbo.github.io/nl2sh/>**

无需登录、无需安装、无需配置。断网时走内置规则库 + 浏览器沙箱，**仍然完整可用**。

---

## 它解决什么问题

Linux 新手卡在三件事上：**不会写命令、不敢敲命令、看不懂命令**。
前两件是工具问题，第三件是教学问题——而市面上"自然语言转命令"的工具只解决第一件，
**命令对不对、为什么这么写，它们不管**。

nl2sh 的做法是：**让命令自己证明自己**。

| 常见做法 | 本作品 |
|---|---|
| 生成一条命令，让用户自己判断对不对 | 生成后**自动**送进沙箱执行，不需要点任何按钮 |
| 执行失败 → 报个错 | 失败 → **把真实报错原文喂回模型** → 重新生成 → 再跑（最多 3 轮） |
| 跑没跑过都能复制 | **跑通之前复制按钮是锁着的** |
| 解释是"术语解释术语" | 逐段解释按"**完全没学过 Linux 的人**"来写（提示词里写死了约束） |

## 核心能力

### 一、AI 那条链路（赛道三的评审重点）

| 能力 | 说明 |
|---|---|
| **AI 调用凭证** | 每张结果卡顶部摊开这次调用的可核对事实：模型名（取自服务端 `health` 回报，不是前端写死的字面量）、**首字节耗时**、**流式分片数**、总耗时、实际端点、以及"密钥只在服务端"。生成过程中另有一条**实时证据条**，滚动模型正在吐出的原文——"确实在流式接收"因此成为看得见的事实，而不是一句声明 |
| **零等待：草稿先行，模型精修** | 按下回车**那一瞬间**就把规则库草稿渲染出来（能复制、能跑、沙箱立刻开始验证），模型到了再原地替换。把原本 11–14 秒的空白期变成"已经有东西了，而且正在变好" |
| **多轮对话** | 问完「找出最大的 10 个文件」可以接着问「那只要今天的呢」。最近 3 轮上下文随请求带上，实测两轮答案里**两个约束同时保住** |
| **AI 数据分析** | 一键让模型读那台服务器的 **400 行真实 nginx 日志**。**统计量先由沙箱里的 `awk`/`sort`/`uniq` 真跑出来，模型只负责解释**——让它自己数数不可靠，让它看着真实数字讲"这说明什么、该查什么"才是它擅长的 |
| **边缘服务端的三件判断** | Cloudflare Worker 不是透传管道：① 把安全约束**追加**进 system 消息（前端被整个换掉也生效）；② 危险意图**前置识别**（命中不拦截，只加严）；③ 上下文**裁剪**（成对砍最旧的问答，system 与最近对话必留）。做过什么通过响应头回告前端，界面上会显示 |

### 二、沙箱（自研，不是仿真占位）

- **48 个命令**是真实现的：文件系统带属主、权限位、修改时间，`&&` / `;` / 多级管道 / 重定向都支持
- 目录树**按权限染色**（可执行绿 / 可写黄 / 只读灰 / 无权限红），判定用的是**与沙箱同一套规则**
- 删除的文件**先红闪两次再塌缩**（否则用户只会看到"少了一行"，注意不到删了什么）
- 一键回滚把整个文件系统恢复到最后一次执行前，并播放可见的回退动画
- `ps` / `systemctl` / `ss` 这类依赖内核与 systemd 的命令是**模拟数据**，界面上会打**警示条**说明——
  教学场景里"以假乱真"比功能少更严重

### 三、教学（这是"入门平台"而不是"工具"的地方）

- **首屏即产品**：打开就是一台正在运行的沙箱（左边带权限染色的目录树、右边终端），不是落地页
- **新手闯关 5 关，三层教学**：关卡开始讲**知识点**（例如"通配符为什么必须加引号：
  不加引号时 shell 会抢先展开它"）→ 第 1 次失败给**为什么错 + 怎么避**（报错归类成
  权限不够 / 路径不存在 / 目录非空 / 沙箱未实现…）→ 第 2 次失败给**能照着敲的具体写法**
- **学习报告**：每次沙箱执行都记一笔（**含手敲终端**），聚合成"练过哪几类操作 /
  在哪里卡住过 / 下一步建议练什么"。记录只存本地、不上传；**刻意不给分数排名**——这是学习工具，不是绩效考核

### 四、离线可用

断网、没有 Key 也完整可用：内置 **50 条已核对并逐条真跑验证过**的任务。
界面上明确区分两态——绿色「AI 实时生成」/ 琥珀色「离线模式 · 没有发出任何网络请求」，
两者一眼可辨。

## 架构

```
浏览器（纯静态，单文件 450 KB）
   │  同源 /api/chat（不通则回退 FALLBACK_ORIGIN）
   ▼
Cloudflare Worker  nl2sh-api          ← 密钥唯一的落脚点
   │  · 注入服务端安全约束（前端无法绕过）
   │  · 危险意图前置识别（命中只加严、不拦截）
   │  · 上下文裁剪（成对砍最旧，保留最近对话）
   │  · 强制 JSON mode、模型白名单、限流 20 请求/分钟/IP
   ▼
智谱 open.bigmodel.cn   glm-4-flash（快速）/ glm-4.7（深度思考）
```

**前端没有"配置 Key"这回事**。密钥只存在 Worker 的环境变量里，界面上只说这一句。

### 模型选型（实测记录，不是抄文档）

| 模型 | 实测结果 |
|---|---|
| `glm-4.7-flash`（规格里提到的那个） | **HTTP 500 / 75.9s / 该 ID 不存在** ✗ |
| `glm-4-flash` | **200 / 0.5s** ✓ **选用** |
| `glm-4.7` | 200 / 4.0s，带 `reasoning_content` → 用作「深度思考」档 |

`response_format: {"type":"json_object"}` 是**强制性约束**：不强制时模型会输出带 ``` 围栏的文本。

## 工程验证

```
全量审计            35 项检查 · 1462 项自动化断言 · 任一项不过即阻断提交
├─ 沙箱自测         97 项（含确定性回归：fixture 里禁止 Math.random / Date.now）
├─ 规则库自测       1255 项（50 条任务逐条真跑）
├─ 模型层自测       59 项（含 8 项 JSON 转义修复回归）
└─ 代理层自测       51 项（含服务端加固 23 项）

真机自测（需联网）   16 项 —— 打已部署的 Worker、真实调模型、再把命令送进沙箱
```

几条值得一提的设计：

- **确定性是硬规则**：沙箱 fixture 里出现 `Math.random` 会被测试直接判失败——
  否则 `du` 的总量每次都不一样，管道样例会自相矛盾
- **审计防的是"我自己会犯的错"**：往说明书清单插条目时我反复打乱编号（**连续八次**），
  现在有一条检查专门盯它，并配了 `scripts/doc-append.mjs` 做自动编号写入
- **"成功但零输出"不判为失败**：`mkdir` / `rm` / `chmod` 本来就该没有输出，
  一刀切会误伤正常命令、平白多跑几轮模型。这类情况只在闭环面板上如实提示

## 本地运行 / 部署

要在本地跑（现场演示用）：

```
现场演示\启动.cmd                      ← Windows 双击即可，会自动挑 Python 或 Node
python -m http.server 8777 --bind 127.0.0.1
node 现场演示/server.mjs 8777
```

> ⚠️ **不要直接双击 `index.html`**：来源是 `file://`，浏览器会限制跨域请求，
> **AI 那条链路走不通**（实测：`file://` 下收到 0 字符，本地 HTTP 下 178 个流式分片正常）。
> 离线规则库在 `file://` 下仍然完整可用。

部署：GitHub Pages（当前线上地址就是它）· EdgeOne Pages（腾讯云国内节点，免备案）·
详见 `deploy/` 目录。

## 已知局限（如实写）

- **沙箱不是真 Linux**：系统级命令（`systemctl` / `ss` / `ps`）是预设场景的模拟数据，界面会明示
- **依赖外部模型服务**：额度耗尽或服务异常时会退到规则库（50 条），功能缩水但不断
- **记录只存本地**：换浏览器或清缓存就重新开始，没有云同步
- **没有做真正的跨引擎实测**：只做了静态扫描（`:has()` / `backdrop-filter` / `@container` /
  `color-mix` 全 0 处，JS 里连可选链都没用），本机只有 Chromium 内核浏览器，
  **不能声称验证过 Firefox / Safari**
- **受众面窄**：只覆盖 Linux 入门阶段的文件与文本操作，进阶运维场景几乎为零
- **「页面能打开」不等于「AI 能用」——这是两个不同的域名**：
  静态页在 `muxinbo.github.io`，模型代理在 `nl2sh-api.zibochen82.workers.dev`。
  实测 `*.workers.dev` 在大陆被 DNS 污染（21 秒超时零响应，DNS 返回 Facebook / Dropbox 的 IP），
  所以**在没有代理的网络下，页面正常显示、但四个 AI 功能一个都出不来，会一直停在「离线模式」**。
  对赛道三这条评分点（「后端智能必须突出」）是伤筋动骨的。
  修法在 `deploy/EdgeOne函数代理-操作步骤.md`：把代理搬到国内节点，或给 Worker 绑一个自定义域名
  （污染的是 `workers.dev` 这个**通配域名本身**，自定义域名走正常 Cloudflare 节点）。
