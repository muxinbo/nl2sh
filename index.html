    关于这个页面

    它解决什么

    新手卡在两步：不知道该敲什么，以及不敢敲。这个工具先给命令，再把命令拆开讲清，最后让它在沙箱里真的跑一遍，让你看见后果再决定要不要用。

    沙箱是什么

    一个用 JavaScript 写的迷你 shell 加内存文件系统，实现了 find、du、rm、chmod、grep、sort、xargs、awk、tar 等命令的真实语义：路径、管道、重定向、退出码，以及属主和权限检查。systemctl、journalctl、ss、ps 这些依赖 Linux 内核与 systemd 的命令走内置桩，输出会明确标注为模拟。

    为什么敢点

    所有改动只发生在浏览器的内存里，不碰你的电脑，而且每次执行前都会自动打快照——不满意就一键时光倒流。真实环境里不可撤销的删除，在这里可以放心试。

    nl2sh · 原型 v0.1 · 纸面模式与应急模式共用同一套结构，只换密度与配色

    演示数据不联网；实际部署版本通过流式接口调用模型，接口不可用时自动降级到本地规则库。
